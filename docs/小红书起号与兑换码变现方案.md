# 小红书起号与「测评兑换码」变现方案

> 配套工具：本仓库 `psyche-survey/` 已是可运行的移动端测评站（5 套测评 + 兑换码解锁系统）。
> 本文档讲清楚：怎么开店、怎么引流、怎么把测评变成可售卖的「兑换码」、以及必须守住的合规红线。

---

## 一、执行摘要

- **能卖，且你最有优势的方向是「自建测评站 + 小红书兑换码变现」**。案例层面，心理/性格类测试在小红书是跑通赛道：有 1.99 元/份、102 天卖 2.4 万份的账号，也有 0.9 元单品卖 10 万+ 份的低粉高变现案例。
- **你的非对称优势是游戏音频专业**。音频素材/模板比泛心理测评竞争小、客单可更高、还有真实背书——建议做「心理测评引流 + 音频 niche 承接」的组合拳。
- **2026 规则已收紧**：小红书教育类目（成人/儿童教育）改为「定向邀约准入」，个人店禁卖课。我们的测评走「电子资源 / 娱乐测试」路线，避开教育类目，定位娱乐与自我探索，合规空间更大。
- **变现闭环**：测评站托管到外网 → 小红书店内上架「测评兑换码」虚拟商品（1.99~9.9 元引流款）→ 用户下单后自动收到兑换码 → 打开站点输入码解锁专业版测评 → 截图分享带来新流量。
- **三条红线**（详见第六节）：不碰医学/诊断结论、心理数据最小化、不夸大宣传、不违规导流私域。

---

## 二、开店主体与资质

| 主体类型 | 适合度 | 说明 |
|---|---|---|
| 个人店 | ⚠️ 受限 | 不能卖课、部分类目受限；适合先跑通「电子资源/测试」轻模式 |
| 个体工商户 | ✅ 推荐 | 门槛低、可开电子资源/虚拟资料类目，税务简单，副业首选 |
| 企业店 | ✅ 可选 | 若后续做品牌/团队化再升级 |

**建议路径**：先用「个体户营业执照」开店，类目选 **「虚拟资料 / 电子资源」** 或平台当前的 **「趣味测试 / 电子文档」** 类目（避开「教育培训」定向邀约类目）。电子资源类目多为「邀约 + 自荐提报」机制，准备好原创/授权声明再提报。

> ⚠️ 腾讯员工提醒：正式铺开前，请先确认公司是否有 **利益冲突 / 经商报备** 要求。

## 三、选品与定价模型

### 3.1 商品结构（漏斗模型）
- **引流款（占 80%）**：单价 0.9 ~ 9.9 元，例如「趣味性格测评兑换码」「今日运气签兑换码」。目标不是赚钱，是攒销量、攒权重、攒自然流量。
- **专业款（占 15%）**：9.9 ~ 29.9 元，例如「大五人格科学画像兑换码」「恋爱依恋类型解读兑换码」。客单稍高、内容更厚。
- **组合/高阶款（占 5%，谨慎）**：可做成「测评 + 解读报告模板」「音频人专属测评包」，但注意平台对高价虚拟商品的审核。

### 3.2 定价心理
- 9.9 元是小红书虚拟商品「决策门槛最低」的价格带，优先用。
- 引流款宁可低（0.9~1.99）换量，靠专业款和后续的音频 niche 内容做利润。

## 四、内容引流打法

### 4.1 账号定位
- 昵称/简介直接关联「心理测评 / 自我探索 / 趣味测试」，例如「心测小站 · 每天一个灵魂小测试」。
- 简介放一句话钩子：「测过都说准的 5 个趣味测评，点我主页看结果」。

### 4.2 笔记选题公式
`【情绪价值】+【身份标签】+【低门槛动作】`
- 「社恐还是社牛？4 道题测出你内心的动物」
- 「谈恋爱总没安全感？先看看你是哪种依恋类型」
- 「打工人周一能量签：今天适合搞钱还是躺平？」
- 「大五人格 10 题速测，你到底是卷王还是佛系」

### 4.3 封面与标题
- 封面：大字标题 + 一个 emoji 结果图（直接复用测评结果卡截图）。
- 标题带「测」「你是」「几分钟」等词，制造参与感。

### 4.4 更新节奏与互动
- 一天 1~3 篇，前期保量；爆款后稳定日更。
- 评论区主动截流：有人问「准不准」，回复「主页第一个测试，自己测完更准～」。
- 结果卡片天然可截图分享，鼓励用户「晒结果」，形成二次传播。

## 五、「测评兑换码」变现链路（本项目已落地）

整条链路已经在 `psyche-survey/` 里跑通，分三步：

### 5.1 生成兑换码（工具端）
- 运行 `tools/gen_codes.js`：
  ```
  node tools/gen_codes.js --count 50 --tier pro --prefix XHX
  ```
- 产出两份文件：
  - `js/codes.js`：前端校验用的码表（`window.CODES = [...]`），站点凭它判断码是否有效。
  - `codes_export.csv`：给卖家的发货清单（code, tier, note, generatedAt），用来对账、防漏发。
- 码格式示例：`XHX-R3YW-CFZE`（前缀-4位-4位，已规避 0/O、1/I 混淆）。

### 5.2 小红书上架 + 自动发货
- 店内上架商品「专业版测评兑换码（大五人格 / 恋爱依恋）」，价格 9.9 元。
- 发货方式二选一：
  - **方式 A（推荐，零成本）**：商品详情写「下单后自动发货，凭短信/站内信里的兑换码打开站点解锁」。用小红书自带虚拟发货或第三方自动发货工具（如阿索奇）把 `codes_export.csv` 导入，买家付款后自动派码。
  - **方式 B**：手动复制码发给买家（仅适合冷启动验证）。

### 5.3 用户解锁（站点端）
- 用户打开站点 → 首页点「输入兑换码」→ 输入 `XHX-XXXX-XXXX` → 前端比对 `window.CODES` → 校验通过则把 `pro` 层级写入浏览器本地存储 → 专业版测评（大五人格、恋爱依恋）立即解锁。
- 逻辑在 `js/redeem.js`：支持层级（free/pro/all）、本地解锁、可恢复锁定。

> 🔒 **安全说明（重要）**：当前演示版把码表打进前端 `codes.js`，任何人都能在源码里看到明文码。这**只适合低客单 + 娱乐测试的冷启动**。规模化后必须改为 **服务端校验 + 数据库核销**（见第七节），否则码会被白嫖。

## 六、合规清单（必须守住）

1. **诊断红线**：抑郁、焦虑、双相、人格障碍等属《精神卫生法》范畴，网测**不得直接下「你得了 XX」结论**。本项目所有结果都定位「娱乐/自我探索」，报告固定加「非专业结论，不能替代诊断」。
2. **数据红线**：心理测评结果属《个人信息保护法》敏感个人信息。本项目作答**仅在浏览器本地计算、不上传、不落库**，从源头规避「敏感信息须加密存储」义务。若日后要存个体结果，需单独同意 + 加密 + 设留存期 + 可删除。
3. **宣传红线**：禁用「100% 精准」「3 分钟测抑郁」「5 分钟知性格」等绝对化/医疗化表述。
4. **导流红线**：小红书对站外导流管控严，优先**站内成交 + 自动发货**，不要在笔记正文硬塞微信/外链。
5. **类目红线**：避开「教育培训」定向邀约类目，走「电子资源 / 趣味测试」。
6. **员工报备**：腾讯员工先确认利益冲突/经商报备要求。

## 七、从演示版到生产级（进阶）

当前 `redeem.js` 是客户端校验，仅适合冷启动。规模上来后建议：

- **服务端校验**：后端 `/redeem` 接口接收码 → 查数据库 → 返回是否有效 + 已核销次数 → 核销后置 `used=true`。
- **码表不出前端**：`codes.js` 改为只存「已登录态」令牌，真实码库在数据库。
- **防刷**：单码单次/有限次使用、绑定设备指纹、限频。
- **可观测**：每笔兑换码对应一笔订单，导出对账报表。

最小可行后端可用任意 BaaS（如平台云函数 + 数据库）实现，前端只改 `redeem.js` 的校验请求即可。

## 八、本周可执行行动清单

1. 确认主体：办理个体户营业执照（或确认个人店能否上电子资源类目）。
2. 站点外网托管：见配套部署说明，把 `psyche-survey/` 发布到可访问域名。
3. 生成首批兑换码：`node tools/gen_codes.js --count 100 --tier pro`。
4. 小红书账号搭建：昵称/简介/首图模板，先发 3 篇笔记测流量。
5. 上架 1 个引流款（1.99 元趣味性格码）+ 1 个专业款（9.9 元大五人格码），接自动发货。
6. 跑 2 周，看哪类测评自然流量最高，再决定加哪些新测试（本项目加测试只改 `js/tests.js` 一个文件）。
