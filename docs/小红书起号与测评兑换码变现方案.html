知微心理 · 项目设计文档（小红书起号与「测评兑换码」变现方案）

本文档是「知微心理」测评站点的项目设计总纲：定位、产品架构、测评体系、兑换码变现模型、小红书起号节奏、合规红线与里程碑。 所有内容均围绕 心理测评虚拟商品 这一方向，不夹杂任何与心理测评无关的专业背景。

一、项目定位

一句话：一个主打「专业感 + 自我探索」的轻量化心理测评平台，先以小红书为流量入口，用低价引流款攒权重，再用兑换码解锁的专业版测评做利润。

品牌：知微心理（Slogan：看见更真实的自己）。 载体：纯前端静态站点（无后端、无数据库），作答在用户本地浏览器完成，零隐私上传风险——这本身就是合规与信任的核心卖点。 核心人群：18–35 岁、对自我成长 / 关系 / 职业有困惑、愿意为「更懂自己」付费的内容消费用户。

为什么是心理测评，而不是泛娱乐测试： - 供给端：专业量表（依恋理论、大五人格 OCEAN）有认知壁垒，比「今天运势」更具复用性与可信度； - 需求端：小红书「自我探索 / 心理成长」内容长期高热，且用户对「专业感」的付费意愿更高； - 变现端：可自然延伸出「测评 + 解读报告」的虚拟商品，客单与复购都更优。

二、产品架构

站点分两层，由「测评兑换码」作为付费闸门：

层级 内容 获取方式 作用
免费版 人格原型、职业天赋、综合能量（各 30 题） 直接作答 引流、攒流量、建信任
专业版 亲密依恋风格、大五人格 OCEAN（各 32 / 30 题） 输入兑换码解锁 利润款、专业背书

兑换码机制（前端演示版）： - tools/gen_codes.js 生成一批码，写入 js/codes.js（演示用，校验在前端）； - 用户输入码 → js/redeem.js 在 localStorage 解锁专业版； - 演示阶段为前端校验，规模化时必须改为服务端核销（防批量盗刷、可统计销量）。

结果页交付物：每套测评输出「类型结论 + 维度画像条 + 特质标签 + 行动建议」四件套，可直接截图分享，天然适合小红书传播。

三、测评体系设计

五套测评，均基于李克特 5 点量表（非常不符合 → 非常符合，0–4 分），引擎自动累加并归一化为 0–100% 维度条。

编号 测评 题量 维度 是否付费
1 人格原型测评 30 探索者 / 战略家 / 疗愈者 / 创造者 / 执行者 / 联结者 免费
2 职业天赋测评 30 创造 / 研究 / 社交 / 实操 / 经营 / 艺术 免费
3 综合能量测评 30 财富 / 情感 / 事业 / 身心 / 心智 免费
4 亲密依恋风格测评 32 安全 / 焦虑 / 疏离 / 恐惧 专业版
5 大五人格 OCEAN 30 开放性 / 尽责性 / 外向性 / 宜人性 / 神经质 专业版

方法论亮点（用于内容背书）： - 专业版引用成熟心理学框架（依恋理论、大五人格），比娱乐测试更有「科学感」； - 维度条可视化，让用户「看见」自己的结构，分享欲强； - 每套测评均含 1–2 道反向计分题，降低盲目认同偏差，提升专业可信度。

详细题面、计分答案与结果解读见同目录《测评题库与答案解析》。

四、兑换码变现模型

4.1 商品分层

  • 引流款（约 80%）：单价 0.9 ~ 1.99 元，如「人格原型测评兑换码」。目标不是赚钱，是攒销量、攒店铺权重、攒自然流量。
  • 专业款（约 15%）：单价 6.9 ~ 9.9 元，如「大五人格 + 依恋风格双测评包」。利润主力。
  • 组合 / 高阶款（约 5%，谨慎）：「测评 + 解读报告模板」「自我探索周计划」，注意平台对高价虚拟商品的审核尺度。

4.2 自动发货

小红书店铺支持虚拟商品自动发货：用户下单 → 系统推送兑换码 → 用户到站点输入即解锁。无需人工值守。

4.3 定价策略

  • 引流款宁可低（0.9~1.99）换量，靠专业款做利润；
  • 专业款给出「单买 vs 双测评包」对比，引导客单提升；
  • 不刻意做低价内卷，靠「专业感 + 结果可分享」建立差异化。

五、小红书起号与内容节奏

5.1 账号定位

  • 昵称 / 简介直接关联「心理测评 / 自我探索 / 人格」，例如「知微心理 · 懂一点自己」；
  • 简介钩子：「5 套专业测评，测完你会更懂自己」；
  • 视觉统一：深靛蓝 + 金的主色调，与站点一致，强化品牌识别。

5.2 内容矩阵

类型 比例 示例 目的
测评安利 40% 「测完破防了，我是恐惧型依恋」 引流到站点
结果解读 30% 「大五人格里神经质高的人，其实很有天赋」 建立专业背书
自我成长 20% 「用能量测评找回生活的重心」 沉淀人设
店铺活动 10% 「新上专业版兑换码，前 50 名半价」 转化

5.3 起号节奏（建议 4 周）

  • 第 1 周：铺 5–8 篇测评安利笔记，统一挂站点链接 / 店铺；
  • 第 2 周：上架 1 个引流款（1.99 元人格原型码）+ 1 个专业款（9.9 元大五人格码），接自动发货；
  • 第 3 周：出 2–3 篇「结果解读」干货，强化专业感，引导店铺转化；
  • 第 4 周：复盘数据，保留高互动选题，汰换低效内容，准备第二轮商品。

六、合规红线

  1. 不碰医学 / 诊断结论：所有测评均标注「自我探索与成长用途，非专业心理 / 医学诊断，不能替代专业评估」。
  2. 数据最小化：作答仅在本地浏览器计算，不上传任何数据；这是信任卖点，也是合规底线。
  3. 不夸大、不制造焦虑：避免「你的依恋有问题」「必须修复」等表述，改用「看见模式、理解自己」的成长语境。
  4. 不违规导流私域：遵守平台规则，不引导加微信 / 外部联系方式完成交易。
  5. 类目红线：避开「教育培训」定向邀约类目，走「电子资源 / 趣味测试 / 虚拟资料」；电子资源多为「邀约 + 自荐提报」，提前准备原创 / 授权声明。
  6. 主体合规：以「个体户营业执照」开店，虚拟商品资质与税务按平台要求办理。

七、技术部署

  • 形态：纯静态站点（HTML + CSS + 原生 JS），可托管于任意静态空间。
  • 当前部署：通过 WorkBuddy「发布为应用」上线，域名形如 *.app-tencent.workbuddy.host（演示 / 内测用）。
  • 去 workbuddy 域名（正式品牌化）三选一： 1. 自定义域名绑定：购买 zhinwei.xin 之类短域名，在托管平台做 CNAME 绑定，最省心； 2. Netlify / Vercel：导入仓库即部署，免费 HTTPS，支持自定义域名； 3. GitHub Pages + CNAME：免费静态托管，绑定自有域名。 （具体步骤见《部署与域名方案》沟通记录；上线前需你确认。）
