# 测评题库与答案解析（5 套完整测评）

> 本文件是 `psyche-survey/` 站点 5 套测评的「维度定义 + 计分方法 + 结果解读」汇总，便于核对内容、做二次创作或印刷成册。
> 所有测评均定位 **自我探索与成长**，非专业心理或医学诊断结论。完整题面以 `js/tests.js` 为准。

---

## 通用计分方法

- **量表**：李克特 5 点——非常不符合(0) / 不太符合(1) / 说不清(2) / 比较符合(3) / 非常符合(4)。
- **单维题**：每题只作用于一个主维度，正向计分（同意=该维度高分）。
- **反向题**：标注「（反向）」的题分数倒序（非常不符合=4，非常符合=0），用于降低盲目认同偏差。
- **归一化**：引擎自动按每维度「理论最高分」把原始分换算成 0–100% 维度条，跨题量可比。
- **判定**：取维度分最高者为主类型；其余维度以百分比条呈现「全景画像」。

## 一、人格原型测评（免费 · 30 题）

**维度（6）**：探索者 / 战略家 / 疗愈者 / 创造者 / 执行者 / 联结者。
**判定**：六维取最高 → 主导人格原型。

**结果解读**
- 🜂 探索者：被未知牵引，天生好奇；适合把好奇落成一个长期项目。
- ♟ 战略家：先看清全局再落子；警惕过度分析导致的行动瘫痪。
- 🌿 疗愈者：高共情、倾听型；记得给自己的共情设边界。
- 🎨 创造者：从空白里造结构的冲动；「完成优于完美」。
- ⚙ 执行者：不折不扣推进到底；偶尔问「还值得做吗」。
- 🕸 联结者：在差异间找共同点；也要经营自己的核心能力。

**样题**
- 我常被尚未被定义的可能性所吸引。（探索者）
- 面对复杂局面，我习惯先看清全局再出手。（战略家）
- 我擅长在人群中牵线搭桥、促成合作。（联结者）

## 二、职业天赋测评（免费 · 30 题）

**维度（6）**：创造型 / 研究型 / 社交型 / 实操型 / 经营型 / 艺术型。
**判定**：六维取最高 → 主导天赋赛道。

**结果解读**
- 💡 创造型：重新定义问题的天赋；配一位执行搭档。
- 🔬 研究型：逻辑严密、追根究底；「先小实验」优于「再想三天」。
- 🤝 社交型：人与人的催化剂；别把「被需要」当自我价值。
- 🛠 实操型：做了才知道；动手前花十分钟想清目标。
- 📈 经营型：在价值交换里看见机会；长期主义是护城河。
- 🎭 艺术型：对美有本能苛求；把审美产品化、可被市场看见。

**样题**
- 我喜欢从零设计一套全新的方案。（创造型）
- 我对市场机会与供需缺口，格外敏锐。（经营型）
- 我对美、节奏与氛围，有近乎苛刻的感知。（艺术型）

## 三、综合能量测评（免费 · 30 题）

**维度（5）**：财富 / 情感 / 事业 / 身心 / 心智（各 6 题）。
**判定**：五维取最高 → 当前主导能量领域；五条维度条呈现「能量流向全景」。

**结果解读**
- 💰 财富能量主导：正把价值做实，把安全感转化为尝试的底气。
- 💗 情感能量主导：被关系与温度滋养，也保留自己的精神角落。
- 🚀 事业能量主导：走在上升轨道，留意其他领域别长期被忽视。
- 🌱 身心能量主导：在养厚根基，把照料好的精力导流去想推进的事。
- 🌌 心智能量主导：向内寻得秩序，把感悟落笔或落行才改变现实。

**样题**
- 我对自己的收入结构和发展空间感到乐观。（财富）
- 我在亲密关系里，能坦然做自己。（情感）
- 我对自己的职业方向，感到笃定。（事业）

## 四、亲密依恋风格测评（专业版 · 32 题）

**维度（4）**：安全型 / 焦虑型 / 疏离型 / 恐惧型（各 8 题）。
**判定**：四维取最高 → 主导依恋风格；四条维度条呈现关系模式全景。

**结果解读**
- 🕊 安全型：近而不黏、远而不慌；稳定本身就是关系里的礼物。
- 🔥 焦虑型：爱得用力也怕得用力；把试探换成直接表达需要。
- 🧊 疏离型：靠近即后退；把「我需要空间」说出口而非冷处理。
- 🌗 恐惧型：既想靠近又怕受伤；先与自己建立安全感，小步靠近。

**样题**
- 当伴侣暂时不在身边，我也能安心做自己的事。（安全型）
- 对方稍微冷淡，我就会怀疑是不是自己哪里做错了。（焦虑型）
- 太亲密会让我本能地想后退一步。（疏离型）
- 我既渴望亲密，又害怕靠太近会受伤。（恐惧型）

> 依恋风格是可观察的「关系模式」，会随经历与觉察流动，并非固定标签。

## 五、大五人格 OCEAN（专业版 · 30 题）

**维度（5）**：开放性 O / 尽责性 C / 外向性 E / 宜人性 A / 神经质 N（各 6 题，含反向题）。
**计分**：正向题按 0→4；反向题（标注「反向」）分数倒序。每维理论最高 24 分，归一化为 0–100%。

**结果画像（按维度百分比解读）**
- 开放性 高：脑洞大、好奇心强；低：偏好熟悉稳妥；中：尝鲜与稳妥间切换。
- 尽责性 高：自律、靠谱；低：随性灵活；中：重要的事会认真。
- 外向性 高：从人群获得能量；低：独处充电；中：能独处也能社交。
- 宜人性 高：温和好相处；低：直接重原则；中：讲理也讲情。
- 神经质 高：情绪敏感易波动，需情绪出口；低：情绪稳定耐操；中：偶尔被戳到。

**动态建议（按显著维度）**
- 神经质高：情绪上来先给自己 10 分钟缓冲，别急着做决定。
- 外向性低：社交别硬撑，主动安排独处补给。
- 开放性高：定期留一点无目的探索时间。
- 尽责性低：用每天 3 件最小清单对抗拖延。
- 宜人性低：表达不同意见前先肯定对方合理处。

**样题**
- 我对陌生的文化与观念，抱有真诚的好奇。（O 正向）
- 比起冒险尝鲜，我更偏爱熟悉稳妥的日常节奏。（O 反向）
- 做事前我会列清楚计划，并按节奏推进。（C 正向）
- 我常在截止前才仓促赶工，计划总赶不上变化。（C 反向）
- 即便有事压在心头，我也能很快恢复平静。（N 反向）

> 本测评为大五人格量表的**简化自我观察版**，仅供自我了解，不能替代专业心理评估。

## 附：如何新增一套测评（技术侧）

在 `js/tests.js` 的 `TESTS` 数组里加一项即可，**无需改动引擎**：
1. 写 `dimensions`（维度 key + 名称）；
2. 写 `questions`，每题 `options` 用 `opt5(维度key, 是否反向)` 生成李克特选项；
3. 写 `profiles`，按维度 key 给出 `{emoji, title, tagline, summary, traits, advice, accent}`；
4. `compute(scores, answers, dims)` 调用 `Engine.dimPct` + `Engine.topDimension` 自动出维度条与结论；
5. 设为付费专业版加 `requireCode: true`，再用 `tools/gen_codes.js` 生成兑换码。

> 题目强调一律使用「」全角引号，避免与 JS 字符串定界符冲突。
